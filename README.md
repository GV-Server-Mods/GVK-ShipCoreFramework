# GVK_ShipCoreFramework

The grid classes of the **GV: Deserts of Kharak (GVK)** server, as a content pack for the Ship Core Framework mod. Each class (Light, Support, Medium, Heavy, Fortress, Small, the scrap, pipeline and shield cores, and the NPC cores) sets how many blocks a grid may have, whether it moves, its speed and boost, and how many of each kind of block it may carry. Workshop item: 3612475191.

## Philosophy
- **The framework enforces the rules, not admins.** A grid that goes over a critical limit has the offending blocks switched off; over a soft limit it takes damage.
- **One ladder to learn.** Every player class uses the same families of limits, so moving up a class only changes the numbers.
- **NPCs are not limited.** The NPC cores have no block, MP or UP limits, only a speed.

## Requirements
- The Ship Core Framework mod, [3552595651](https://steamcommunity.com/sharedfiles/filedetails/?id=3552595651).
- Loaded with the rest of the server mods: [Steam collection](https://steamcommunity.com/sharedfiles/filedetails/?id=2650582206).

## Grid classes
Speed and boost are fractions of the framework's maximum speed. MPs (Mobility Points) are charged for thrusters and suspension; UPs (Utility Points) for weapons, welders, drills, production, rotors, hinges, pistons and grinders. The other caps (wind and solar, drills, welders, grinders, relic weapons and so on) are in each core's XML file.

## Operator cheat sheet
| What | File |
| --- | --- |
| One core's block cap, speed, MP and UP budget and per-type caps | `Content/Data/<beacon subtype>_core.xml` (the table above lists them) |
| Which blocks count toward which limit group | `Content/Data/ShipCoreConfig_Groups.xml` |
| The profile for grids with no core | `Content/Data/ShipCoreConfig_No_Core.xml` |
| World options (which no-core profile is used, combat logging, whether AI factions are ignored) | `Content/Data/ShipCoreConfig_World.xml` |

After a change, lint the content with `sc_lint.py` from the `se-dev-shipcore` skill:

```powershell
python <path-to-skill>/scripts/sc_lint.py Content --world Content/Data/ShipCoreConfig_World.xml
```

Beacon counts per player or faction are not set here; the beacon limiter mod does that.
